# 앱 폰트 넣는 곳

이 폴더에 `.ttf` 또는 `.otf` 파일을 넣으면 앱이 시작할 때 자동으로 그 폰트를 사용합니다.
(없으면 시스템에 설치된 Pretendard → SUIT → 나눔스퀘어라운드 → 맑은 고딕 순으로 찾습니다.)

추천 무료 폰트:
- Pretendard — https://github.com/orioncactus/pretendard/releases (UI 가독성 표준)
- SUIT — https://sun.fo/suit
- 나눔스퀘어라운드 — https://hangeul.naver.com/font (동글동글 컨셉)
- 무료 한글 폰트 모음 — https://noonnu.cc
